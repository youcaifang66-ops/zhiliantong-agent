# 智练通十次迭代路线

1. `v0.1` 健身领域 MVP：领域数据、意图路由、提示词、训练记录查询与基础测试。
2. `v0.2` 类型化工具：Pydantic 入参、统一错误模型、幂等写入。
3. `v0.3` 三层记忆：窗口、向量记忆、摘要记忆、去重与时间衰减。
4. `v0.4` 可溯源检索：BM25 + Embedding + RRF、引用和检索评测。
5. `v0.5` LangGraph 工作流：计划、执行、观察、恢复和人工确认。
6. `v0.6` Agent 评测：Golden Query、轨迹评测、失败分类与回归门禁。
7. `v0.7` 持久化与恢复：PostgreSQL、Redis、检查点、超时和重试。
8. `v0.8` API 与安全：SSE 事件协议、权限、限流、输入输出护栏。
9. `v0.9` 产品化：React 界面、Docker Compose、结构化日志和指标。
10. `v1.0` 面试版本：部署演示、架构图、压测报告、复现实验和面试文档。

根目录的《智练通_十次迭代路线.md》记录了每次提交的详细验收口径。
